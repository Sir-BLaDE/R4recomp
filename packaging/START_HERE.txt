R4 Recompiled @VERSION@  (Windows x64)
=====================================

R4 - Ridge Racer Type 4, Japanese release (SLPS-01798, the R4 + JogCon
edition), statically recompiled with psxrecomp, with the "60FPS + Widescreen
Patch V2" GameShark codes built in as mods.

1. Run R4_Recompiled.exe.
2. On first launch pick YOUR OWN disc image of SLPS-01798 (disc 1, "R4").
   .chd, .cue/.bin and .iso are accepted. No disc data ships in this folder.
3. Mods page -> "R4 60 FPS + Widescreen Patch V2": all four features are on
   by default and each can be switched off on its own:
     - 60 FPS               (also enables the 300% CPU overclock it needs)
     - 16:9 Widescreen      (game's own 16:9 FOV/UI, stretched 16:9 output,
                             generic widescreen hack kept off)
     - Opponents on minimap (Grand Prix / Extra Trial)
     - 16:9 opening FMV
   Recommended with 16:9: enable the built-in "PGXP" mod (less background
   wobble/distortion).

Save states made with the GameShark mods enabled are kept separate from
stock save states. Memory cards are shared.

BIOS: the bundled open-source OpenBIOS is used by default; no BIOS dump needed.
Licenses for psxrecomp, recomp-ui, OpenBIOS and third-party components are in
licenses/ and bios/.
